# 🛍️ QueueLess — Smart Campus Queue Management System

<p align="center">
  <b>Skip the Queue. Save Your Time. 🚀</b>
</p>

A C++17-based campus queue management system that allows students to order products and services from campus shops, receive unique tokens, and track their orders without standing in long queues.

## ✨ Features

- 🏪 **Shop Management** – Browse and manage multiple campus shops.
- 🛒 **Order Placement** – Select products/services and specify quantities.
- 🎟️ **Token Generation** – Get a unique token for every order.
- 💰 **Automatic Billing** – Calculate order totals automatically.
- ⏳ **Order Tracking** – Track Preparing, Ready and Collected statuses.
- 👨‍💼 **Admin Panel** – Add/remove shops and services, and view all orders.
- 💾 **File Handling** – Store and retrieve data using text files.

## 🛠️ Tech Stack

- **Language:** C++17
- **Concepts:** OOP, Inheritance, Encapsulation
- **Data Structures:** STL Vectors
- **Storage:** File Handling (`.txt`)
- **Libraries:** iostream, fstream, vector, string, ctime

## 🧠 OOP Concepts

- **Inheritance:** `Customer` and `Admin` inherit from the base class `User`.
- **Encapsulation:** System data and operations are organized within classes.
- **Classes & Objects:** Used to represent users and manage the application.
