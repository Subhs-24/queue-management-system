# QueueLess — Boxed & Colored Console Menus

- Box-style main, customer, and admin menus.
- ANSI colored borders, options, shop/service lists, and selected messages.
- Preserves file-based order management and timestamp-based preparation timer.

Compile:
```bash
g++ -std=c++17 main.cpp -o queueless
```
On Windows:
```bash
.\queueless.exe
```

Admin login: `admin` / `admin123`

Use the VS Code integrated terminal or a modern Windows Terminal for ANSI colors.
